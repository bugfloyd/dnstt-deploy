# 🚀 راهنمای اتصال DNSTT (فقط مخصوص SSH)

**Languages:** [English](README.md) | [فارسی](README-fa.md)

1. اپلیکیشن HTTP Injector برای [اندروید](https://play.google.com/store/apps/details?id=com.evozi.injector) یا [آیفون](https://apps.apple.com/us/app/http-injector/id1659992827) دانلود کنید
2. فایل کانفیگ نمونه را از [اینجا](example.ehi) دانلود کنید
3. فایل کانفیگ رو در اپ ایمپورت کنید
4. بروید به تنظیمات اپ `settings > Secure Shell (SSH) > Password` و پسوردی که برای یوزر `dnstt` روی سرور ساختید رو اینجا وارد کنید
5. بروید بخ تنظیمات `settings > DNSTT (DNS)` و:
6. نام دامنه خود را در این قسمت وارد کنید `DNSTT Nameserver`
7. کلید عمومی که بعد از اجرای اسکریپ دریافت کردید را اینجا وارد کنید `DNSTT Public Key`
8. و یک سرور dns ایرانی را در این قسمت وارد کنید `DNS Resolver Address`. میتونید تمام dns های ایرانی را [اینجا](https://dnstt.network/ir_dns_servers.txt) پیدا کنید.
