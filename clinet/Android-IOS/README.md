# 🚀 DNSTT Connectivity Guide (SSH only)

**Languages:** [English](README.md) | [فارسی](README-fa.md)

1. Download HTTP Injector for [Android](https://play.google.com/store/apps/details?id=com.evozi.injector) or [IOS](https://apps.apple.com/us/app/http-injector/id1659992827)
2. Download the example config file [here](example.ehi)
3. Import the config file into the app
4. Go to the `settings > Secure Shell (SSH) > Password` and enter your ssh password you made for `dnstt` user on the server
5. Go to the `settings > DNSTT (DNS)` and:
6. Add you domain name to `DNSTT Nameserver`
7. Add your Public Key to `DNSTT Public Key`
8. And add a valid Iranian DNS server to `DNS Resolver Address`. you can find them [here](https://dnstt.network/ir_dns_servers.txt) one od them may work for you.
