# 🚀 راهنمای اتصال DNSTT (فقط مخصوص SOCKS5)

**Languages:** [English](README.md) | [فارسی](README-fa.md)

این مراحل را دنبال کنید تا یک سرور DNS کاربردی پیدا کرده و یک اتصال تونل امن برقرار کنید.

## 📦 مرحله ۱: دانلود

1. فایل‌های [کلاینت dnstt](https://dnstt.network)، [`ir_dns_servers.txt`](https://dnstt.network/ir_dns_servers.txt) و [`dns-validator-windows.ps1`](dns-validator-windows.ps1) را در یک پوشه روی دسکتاپ خود دانلود کنید.
   *مطمئن شوید که `dnstt-client-windows-amd64.exe`، `ir_dns_servers.txt` و `dns-validator-windows.ps1` در یک دایرکتوری قرار دارند.*
2. یک فایل `server.pub` در همان دایرکتوری ایجاد کرده و کلید عمومی خود را در آن قرار دهید.

## 🔍 مرحله ۲: یافتن یک DNS کاربردی

قبل از اتصال، باید یک سرور DNS که با اینترنت شما کار می‌کند پیدا کنید.

1. روی دکمه "Start" کلیک راست کرده و "Terminal" یا "PowerShell" را انتخاب کنید.
2. با استفاده از دستور `cd` به پوشه خود بروید (مثلاً `cd C:\Users\YourName\Desktop\dnstt`).
3. اسکریپت بررسی را با تایپ کردن این دستورات اجرا کنید:
```powershell
   Set-ExecutionPolicy Bypass -Scope Process
   .\dns-validator-windows.ps1
```


4. منتظر بمانید تا اسکریپت به پایان برسد. یک فایل به نام `working_dns_windows.txt` ایجاد می‌شود که فقط IP‌هایی که با موفقیت متصل شده‌اند را شامل می‌شود.

> توجه: فایل `ir_dns_servers.txt` شما باید تمیز باشد. باید فقط شامل آدرس‌های IP خام باشد (مثلاً `217.218.127.104`)، هر کدام در یک خط. [نمونه اینجا](ir_dns_servers.txt).

## 🛠️ مرحله ۳: برقراری تونل

1. "Command Prompt (CMD)" را به عنوان "Administrator" باز کنید.
2. با استفاده از دستور `cd` به پوشه خود بروید (مثلاً `cd C:\Users\YourName\Desktop\dnstt`).
3. یک IP با وضعیت "SUCCESS" از مرحله قبل انتخاب کنید.
4. `t.example.com` را در دستور زیر با نام دامنه خود جایگزین کنید.
5. `DNS_SERVER_IP` را در دستور زیر با IP کاربردی خود جایگزین کرده و آن را اجرا کنید:

   dnstt-client-windows-amd64.exe -udp DNS_SERVER_IP:53 -pubkey-file server.pub t.example.com 127.0.0.1:7000

6. این پنجره را باز نگه دارید. تونل شما اکنون روی پورت `7000` فعال است.

## 🌐 مرحله ۴: پیکربندی برنامه‌های خود

برای استفاده از اینترنت از طریق این تونل، برنامه‌های خود را برای استفاده از "SOCKS5 Proxy" پیکربندی کنید:

آدرس پروکسی: `127.0.0.1`
پورت: `7000`

## مثال‌ها:

تلگرام: Settings > Advanced > Connection Type > Use custom proxy > SOCKS5.
مرورگر (SwitchyOmega): یک پروفایل SOCKS5 جدید با آدرس و پورت بالا ایجاد کنید.

## ⚠️ عیب‌یابی و رفع مشکل

### پورت مشغول است؟

اگر خطایی مبنی بر اینکه پورت `7000` در حال استفاده است می‌بینید، یا اگر اتصال شروع نمی‌شود، ممکن است یک نمونه قبلی در پس‌زمینه گیر کرده باشد.

**برای رفع این مشکل:**

1. CMD را به عنوان Administrator باز کنید.
2. شناسه پروسه (PID) که از پورت استفاده می‌کند را پیدا کنید:

   netstat -ano | findstr :7000

3. پروسه را با استفاده از PID پیدا شده در انتهای خط از بین ببرید (`1234` را با PID واقعی خود جایگزین کنید):

   taskkill /F /PID 1234


### هیچ IP کار نمی‌کند؟

مطمئن شوید که فایروال یا آنتی‌ویروس شما `dnstt-client-windows-amd64.exe` را مسدود نمی‌کند. همچنین می‌توانید `ir_dns_servers.txt` خود را با سرورهای جدیدتر به‌روزرسانی کنید.

### تمیز کردن [ir_dns_servers.txt](ir_dns_servers.txt)

اگر از یک `ir_dns_servers.txt` جدید استفاده می‌کنید، ممکن است نیاز باشد آن را از هرگونه کامنت یا خط خالی پاک کنید.
